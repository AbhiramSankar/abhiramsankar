## GETTING STARTED

If you would like to use this portfolio design as a starting template:

### 1. Clone this repo

```bash
git clone https://github.com/AbhiramSankar/abhiramsankar
cd abhiramsankar
```

### 2. Install dependencies

```bash
npm install
```
or
```bash
yarn
```

### 3. Start development server

```bash
npm install
```
or
```bash
yarn dev
```

### 4. Build for Production

```bash
npm run build
```
or
```bash
yarn build
```
